Music Project - Guia de Uso

Como usar o MVP atual para gerar arquivos .tg do TuxGuitar a partir de um contrato JSON de melodia ou de um audio monofonico simples.

Funciona hoje JSON de melodia para .tg e audio monofonico simples para .tg.
Entrada ideal WAV limpo, uma unica melodia, sem acordes, com BPM conhecido.
Saida Arquivo .tg abrivel no TuxGuitar e, opcionalmente, contrato JSON de debug.

Visao geral

O projeto esta organizado em tres camadas conceituais:

  1. Audio de entrada.
  2. Conversao para dados simbolicos de melodia, no formato MelodyScoreContract.
  3. Escrita do arquivo .tg usado pelo TuxGuitar.

No MVP atual, a camada de audio aceita apenas melodias monofonicas. Isso quer dizer: uma nota por vez, sem acordes e sem mistura de varios instrumentos. A separacao de instrumentos e a transcricao polifonica ainda sao fases futuras.

Importante: este sistema ainda nao transcreve uma musica completa arbitraria com bateria, baixo, voz, guitarra base e guitarra solo. Para testar agora, use uma melodia isolada.

Pre-requisitos

  • Windows com PowerShell.
  • Python 3.11 ou superior.
  • TuxGuitar instalado para abrir o arquivo .tg gerado.
  • Um audio monofonico limpo, preferencialmente .wav, para testar a camada de audio.

Os exemplos abaixo assumem que voce esta na raiz do repositorio: 

cd E:\music-project

Instalacao

1. Criar ambiente virtual

py -3.11 -m venv .venv

2. Instalar o projeto com suporte de audio CPU

.\.venv\Scripts\python.exe -m pip install -e ".[audio]"

Essa instalacao habilita o backend librosa-pyin, que e o caminho baseline ja validado para audio monofonico.

3. Opcional: instalar suporte PyTorch/torchaudio

.\.venv\Scripts\python.exe -m pip install -e ".[audio,torch]"

O backend torchaudio pode usar CUDA quando o PyTorch instalado reconhecer a GPU. Se torch.cuda.is_available() retornar False, instale o wheel correto pelo seletor oficial do PyTorch. 

.\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"

Teste rapido

Para testar a escrita de .tg sem audio, use o contrato de exemplo que ja existe no repositorio: 

.\.venv\Scripts\melody-to-tg.exe examples\simple_melody_contract.json out\simple_from_contract.tg

Se funcionar, a CLI imprime o caminho do arquivo criado: 

out\simple_from_contract.tg

Abra esse arquivo no TuxGuitar para verificar a partitura/tablatura.

Audio para .tg

Use audio-to-tg quando voce tiver um arquivo de audio com uma melodia simples. O BPM precisa ser informado manualmente nesta versao.

Comando recomendado para primeiro teste

.\.venv\Scripts\audio-to-tg.exe caminho\melodia.wav out\melodia.tg --bpm 120 --backend librosa-pyin --instrument guitar --contract-output out\melodia.contract.json

O comando gera dois arquivos importantes:

Arquivo Uso
out\melodia.tg Arquivo final para abrir no TuxGuitar.
out\melodia.contract.json Representacao intermediaria para debug: notas detectadas, duracoes, cordas e casas.

Exemplo com baixo

.\.venv\Scripts\audio-to-tg.exe caminho\baixo.wav out\baixo.tg --bpm 90 --backend librosa-pyin --instrument bass --contract-output out\baixo.contract.json

Exemplo tentando torchaudio com CUDA

.\.venv\Scripts\audio-to-tg.exe caminho\melodia.wav out\melodia_cuda.tg --bpm 120 --backend torchaudio --device cuda --instrument guitar --contract-output out\melodia_cuda.contract.json
Para o MVP, comece com librosa-pyin. O backend torchaudio e util para experimentos com GPU, mas depende da instalacao correta de PyTorch/CUDA no ambiente.

Contrato JSON para .tg

Use melody-to-tg quando voce ja tiver a saida da camada 2, isto e, um arquivo JSON no formato MelodyScoreContract. 

.\.venv\Scripts\melody-to-tg.exe caminho\contrato.json out\saida.tg

Esse caminho e a forma mais estavel de testar a camada 3. Ele nao faz analise de audio; apenas valida o contrato e escreve o arquivo .tg.

Contrato de exemplo

O arquivo examples\simple_melody_contract.json mostra a estrutura esperada. A documentacao detalhada do contrato esta em docs\05-layer2-layer3-melody-contract.md.

Referencia da CLI

audio-to-tg

Argumento Obrigatorio Descricao
input Sim Caminho do audio de entrada.
output Sim Caminho do arquivo .tg de saida.
--bpm Sim Tempo da musica em batidas por minuto.
--backend Nao librosa-pyin ou torchaudio. Padrao: librosa-pyin.
--device Nao auto, cpu ou cuda. Usado pelo backend torchaudio.
--instrument Nao guitar ou bass. Padrao: guitar.
--title Nao Titulo gravado no contrato e no arquivo de saida. Padrao: nome do arquivo de entrada.
--quantization Nao Grade ritmica usada para quantizar eventos. Valores: 4, 8, 16, 32, 64. Padrao: 16.
--sample-rate Nao Taxa de amostragem usada no processamento. Padrao: 22050.
--fmin-midi Nao Menor nota MIDI esperada para rastreamento de pitch. Padrao: 40.
--fmax-midi Nao Maior nota MIDI esperada para rastreamento de pitch. Padrao: 88.
--contract-output Nao Caminho para salvar o JSON intermediario gerado a partir do audio.

melody-to-tg

Argumento Obrigatorio Descricao
input Sim Caminho do contrato JSON.
output Sim Caminho do arquivo .tg de saida.

Para ver a ajuda direto pela CLI:

.\.venv\Scripts\audio-to-tg.exe --help
.\.venv\Scripts\melody-to-tg.exe --help

Troubleshooting

No module named music_project

O projeto nao foi instalado no ambiente atual. Rode: 

.\.venv\Scripts\python.exe -m pip install -e ".[audio]"

librosa backend requires optional dependencies

As dependencias opcionais de audio nao foram instaladas. Use a instalacao com extra audio: 

.\.venv\Scripts\python.exe -m pip install -e ".[audio]"

O arquivo .tg saiu vazio ou com notas erradas

  • Confirme que o audio tem apenas uma melodia, uma nota por vez.
  • Confirme o BPM usado em --bpm.
  • Tente exportar o audio como WAV mono limpo.
  • Restrinja a faixa de pitch com --fmin-midi e --fmax-midi.
  • Gere --contract-output e inspecione as notas detectadas antes de abrir no TuxGuitar.

CUDA foi pedida, mas nao funciona

Verifique primeiro se o PyTorch reconhece a GPU: 

.\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"

Se o resultado for False, o backend torchaudio --device cuda nao vai funcionar nesse ambiente. Use --backend librosa-pyin ou instale o wheel CUDA correto do PyTorch.

Limites atuais

  • Nao separa instrumentos de uma musica mixada.
  • Nao transcreve acordes nem polifonia.
  • Nao detecta BPM automaticamente.
  • Nao detecta bends, slides, vibrato, palm mute ou tecnicas especificas de guitarra.
  • O mapeamento string/fret usa uma heuristica simples, nao uma digitacao musical ideal.
